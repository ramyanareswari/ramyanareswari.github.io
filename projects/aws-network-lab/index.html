AWS EC2 Cloud & Network Engineering Lab

Cloud and networking lab: provisioning, containerised services and traffic analysis.

AWS EC2DockerLinuxWiresharktcpdump
Scope
Provisioning, deployment, traffic analysis
Environment
Ubuntu on AWS EC2
Focus
Protocol-level inspection

Overview

Configured an Ubuntu environment on AWS EC2, deployed and tested network services using Docker, and analysed HTTP/2, TLS/QUIC, DNS and network traffic using Wireshark and tcpdump.

Features

  • Instance provisioning — Ubuntu configured on EC2.
  • Containerised services — Network services deployed and tested with Docker.
  • Protocol analysis — HTTP/2, TLS/QUIC and DNS traffic captured and inspected.
  • Packet-level tooling — Wireshark and tcpdump used to analyse the traffic.
